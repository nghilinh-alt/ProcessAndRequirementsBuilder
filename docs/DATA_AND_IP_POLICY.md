# Data & IP policy (engine repo)

**Owner:** Rogue Night Pty Ltd. This repo is the company's background IP.

## Never commit
- Any client document, dataset, BRD, process map or requirement set (including WorkCover Qld / FCM material).
- Client names in prompts, tests, fixtures or benchmark cases.
- API keys, tokens or `.env` files.
- Tax, R&DTI claim or financial documents. Keep those in the company's private records, not the engine repo.

## Allowed
- Generic engine code, schemas, prompts and config.
- Rogue Night-built synthetic benchmark cases modelled on the *type* of problem only.
- Experiment logs describing designs, settings and metrics.

## Working rules
- Develop on Rogue Night devices and accounts, outside client hours and systems.
- If unsure whether something counts as client material, leave it out and ask Linh.
